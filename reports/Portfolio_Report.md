# Portfolio Risk & Return Analysis

## Objective
Analyze portfolio performance using Modern Portfolio Theory and simulate optimal asset allocations.

## Data
Monthly stock prices of AAPL, MSFT, GOOG, and AMZN for 2024.

## Methodology
- Calculated monthly returns
- Annualized return & covariance matrix
- Simulated 5000 random portfolios
- Computed Sharpe ratio
- Generated Efficient Frontier

## Results
The simulation shows the tradeoff between risk and return.
Portfolios with higher Sharpe ratios offer better risk-adjusted returns.

## Business Application
This model can support investment decision-making, capital allocation strategy, and risk management analysis.
